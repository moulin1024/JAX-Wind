# Horns Rev 1 warmup feasibility test

Tested on 2026-09-15 in allocation 30244593, node ravg1177, on one
NVIDIA A100-SXM4-40GB with JAX 0.10.0. Configuration:
`fv_workflow_512x512x256_16x16x4.toml`.

- Grid: 512 x 512 x 256 (67,108,864 cells), float32.
- Cell spacing: 16 x 16 x 4 m; domain: 8192 x 8192 x 1024 m.
- Neutral offshore initialization, z0 = 0.0002 m, target U(70 m) = 8 m/s.
- A matching 256-level profile uses the case log-law and RMS formulas.
- Pressure acceleration is adjusted to u*^2 / 1024 for the new height.
- Periodic warmup workflow: FFT/Thomas pressure solver, RK3, adaptive CFL 0.9.
- Retained physical warmup target: 36000 s.

## Measured result

The bounded test completed 200 steps, reaching 269.006409 s, and paused
successfully with a restart checkpoint. All saved numerical state arrays
were checked and are finite. Final maximum divergence was 6.007e-8 s^-1;
the mean streamwise velocity at the 70 m cell centre was 8.01624 m/s.

GPU memory sampled every 5 s peaked at 31,181 MiB (30.45 GiB). Sampling
may miss brief peaks. Steady advancement was 5.164 steps/s (0.194 s/step),
measured over the final two 50-step blocks. Advancement timing excludes
initialization, diagnostics and checkpoint I/O. The final compressed
checkpoint is 1.555 GiB; compression took several minutes.

The runtime reports final CFL = 4.6092 using the configured 6 s timestep
cap. It is not the actual adaptive-step CFL. The driver chooses each step
from the current velocity with CFL ceiling 0.9; the final velocity implies
a next convective timestep of approximately 1.172 s. Individual accepted
timesteps are not stored by this atmospheric state. Average timestep over
the test was 1.345 s.

This establishes short-run feasibility on the allocated GPU. It does not
establish long-run stability or developed turbulence. The 290 B/cell
estimate in the case README underestimates this run's observed allocation.

```bash
JAX_PLATFORMS=cuda XLA_PYTHON_CLIENT_PREALLOCATE=false \
XLA_FLAGS=--xla_gpu_autotune_level=0 PYTHONPATH=src \
/raven/u/limo/venvs/numba_cuda_waterboa/bin/python -u -m jaxwind workflow \
  cases/HornsRev1/fv_workflow_512x512x256_16x16x4.toml \
  --stage warmup \
  --output outputs/hornsrev1_512x512x256_16x16x4_smoke_30244593 \
  --max-steps 200
```

with `--resume`; to repeat from scratch, choose a fresh output directory.
